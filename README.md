Sistema de Controle Financeiro

Projeto desenvolvido em Python com o objetivo de criar um sistema simples de controle financeiro pessoal, permitindo registrar receitas, despesas e acompanhar movimentações financeiras.

Atualmente, o projeto está em desenvolvimento e será aprimorado gradualmente, com a implementação de novas funcionalidades.

-Funcionalidades-

-  Menu principal interativo.
-  Opção para registrar receitas.
-  Entrada de descrição e valor da receita.
-  Registro de despesas.
-  Consulta de saldo.
-  Listagem de transações.
-  Armazenamento dos dados.

-Tecnologias utilizadas-

- **Python** — linguagem utilizada no desenvolvimento.
- **Git** — controle de versão.
- **GitHub** — hospedagem e acompanhamento do projeto.


 Como executar

1. Certifique-se de ter o Python instalado.
2. Clone este repositório:

```bash
git clone https://github.com/henriquevicent/controle-financeiro.git
```

3. Entre na pasta do projeto:

```bash
cd controle-financeiro
```

4. Execute o programa:

```bash
python main.py
```
